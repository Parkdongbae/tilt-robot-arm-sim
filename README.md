# 🦾 기울기 로봇팔 시뮬레이터

스마트폰 2대의 **기울기 센서**로 가상 공간의 **3축 로봇팔**을 조종해 물건을 집어 옮기는 시뮬레이터입니다.

- **왼쪽 폰**: 로봇팔 3축(베이스 회전 · 어깨 · 팔꿈치) 조종
- **오른쪽 폰**: 집게 열고 닫기, 배경 전환, 시점 전환
- **PC 화면**: 3D 시뮬레이터 (Three.js)
- 미션을 완료하면 다음 단계로 자동 이동하고, **3단계부터 난이도가 올라갑니다**

## 실행 방법

준비물: [Node.js](https://nodejs.org) 18 이상, PC와 스마트폰 2대 (모두 **같은 Wi‑Fi**)

```bash
npm install
```

```bash
npm start
```

1. PC 브라우저에서 `http://localhost:3000` 을 엽니다.
2. 화면의 QR 코드 2개를 각각 왼쪽/오른쪽 폰으로 찍어 접속합니다.
3. 폰에서 "연결이 비공개로 설정되어 있지 않습니다" 경고가 나오면 **[고급] → [계속(방문)]** 을 누릅니다.
   (폰의 기울기 센서는 HTTPS에서만 동작해서, 서버가 자체 서명 인증서를 만들어 씁니다.)
4. 폰에서 **시작하기**를 누르면 센서가 켜집니다. 두 폰이 모두 연결되면 게임이 자동으로 시작됩니다.

> 폰이 접속되지 않으면 Windows 방화벽에서 Node.js의 "개인 네트워크" 접근을 허용해 주세요.

## 조작법

폰은 **화면이 위로 오도록 눕혀서** 잡습니다. 시작 순간의 자세가 기준(영점)이 되며, 언제든 **영점 맞추기** 버튼으로 다시 맞출 수 있습니다.

| 왼쪽 폰 (로봇팔) | 동작 |
|---|---|
| 좌우로 기울이기 | 베이스 회전 |
| 앞뒤로 기울이기 | 어깨 (앞으로 숙이면 팔이 앞/아래로) |
| 아래 버튼을 누른 채 앞뒤로 기울이기 | 팔꿈치 |
| (옵션) 비틀기 | 팔꿈치 |

| 오른쪽 폰 (집게/배경) | 동작 |
|---|---|
| 앞으로 숙이기 | 집게 닫기 (물건 잡기) |
| 다시 평평하게 | 집게 열기 (물건 놓기) |
| 좌/우로 휙 기울였다 돌아오기 | 배경 전환 (5종) |
| 버튼 | 집게 잠금, 시점 전환, 미션 다시 하기 |

집게 아래의 **빨간 선과 점**이 물건이 떨어질 위치를 보여 줍니다.

### 키보드 (폰 없이 테스트)

`A/D` 베이스 · `W/S` 어깨 · `R/F` 팔꿈치 · `Space` 집게 닫기 · `G` 집게 잠금 · `Q/E` 배경 · `C` 시점 · `Backspace` 다시 하기 · `N` 다음 단계 건너뛰기

## 미션 단계

| 단계 | 내용 |
|---|---|
| 1 | 첫 번째 운반 — 상자 하나를 목표 구역으로 |
| 2 | 빙글 돌려서 옮기기 — 베이스 크게 회전 |
| 3 ⚠ | 색깔 분류 — **여기부터 제한 시간** |
| 4 | 장애물 넘기 — 벽 위로 들어 옮기기 |
| 5 | 높은 선반 — 높은 받침대 위에 놓기 |
| 6 | 탑 쌓기 — 상자 3개를 순서대로 쌓기 |
| 7 | 움직이는 컨베이어 — 움직이는 구역에 타이밍 맞춰 놓기 |
| 8~ | 자동 생성 — 물건 수↑, 구역 크기↓, 시간↓, 벽·높은 구역·움직이는 구역↑ |

시간 안에 못 끝내면 같은 단계를 다시 시작합니다. 점수는 물건 1개당 100점과 남은 시간 보너스로 계산합니다.

## 파일 구조

```
server.js            HTTP(3000)·HTTPS(3443) 서버 + WebSocket 중계, QR 생성
public/index.html    PC 시뮬레이터 화면
public/sim.js        로봇팔·충돌·집기·미션 진행
public/missions.js   단계별 미션 정의 / 자동 생성
public/themes.js     배경 테마 5종
public/left.html     왼쪽 폰 조종기
public/right.html    오른쪽 폰 조종기
public/controller.js 폰 공통 (센서 권한, 연결, 영점)
```
